# Unofficial Fortnite Creative Documentation

An organized, educational knowledge repository for **Fortnite Creative**, designed for learners, educators, creators, curriculum developers, and AI assistants.

The repository brings together technical documentation, beginner-friendly guides, terminology, gameplay-system patterns, testing practices, educational applications, and a chapter on translating social ideas into playable mechanics.

> **Start here:** [`INDEX.md`](INDEX.md) is the main navigation file and the authoritative map of the repository.

---

## Purpose

This repository was created to make Fortnite Creative knowledge easier to navigate, understand, teach, and apply.

It is intended to support:

- New creators learning Fortnite Creative step by step.
- Educators developing game-based learning activities.
- Students working with structured learning materials.
- Designers building cooperative and socially meaningful experiences.
- AI assistants that need a clear source hierarchy and topic-routing system.

The repository is primarily written in **Hebrew**, while official interface names, Devices, Events, Functions, and other technical terms remain in English where appropriate.

---

## Repository Contents

The main knowledge layer contains **15 numbered core files (`00–14`)** covering:

- Repository navigation and source hierarchy.
- Beginner workflows and first steps.
- Interface navigation, the Phone Tool, controls, and shortcuts.
- Island Settings, permissions, and game rules.
- World building, level design, Prefabs, and Galleries.
- Devices, Events, Functions, triggers, and conditions.
- Movement, zones, barriers, and transitions.
- Players, Teams, Classes, Spawn, Cameras, and rounds.
- Objectives, progression, scoring, Items, and resources.
- HUD, communication, audio, video, and player feedback.
- Characters, AI, lighting, environment, and VFX.
- Gameplay patterns and Device recipes.
- Playtesting, debugging, memory, publishing, and safety.
- Educational uses, lesson plans, and facilitation.
- A Hebrew–English Fortnite Creative glossary.

The repository also includes:

- A complete student-oriented learning guide.
- An expanded technical dictionary.
- A practical chapter on social game design in Fortnite Creative.

For the complete file map and recommended source for each topic, see [`INDEX.md`](INDEX.md).

## How to Use This Repository

### For learners and creators

1. Begin with [`01_מדריך_מעשי_למתחילים_Fortnite_Creative.md`](01_מדריך_מעשי_למתחילים_Fortnite_Creative.md).
2. Use [`ספר הדרכה - מצב יצירתי פורטנייט.md`](<ספר הדרכה - מצב יצירתי פורטנייט.md>) for a structured learning sequence.
3. Use [`14_מילון_מושגים_Fortnite_Creative_HE_EN.md`](14_מילון_מושגים_Fortnite_Creative_HE_EN.md) when a technical term or interface label is unclear.
4. Use [`INDEX.md`](INDEX.md) to locate the specialist file for a specific question.

### For educators

Use the technical files as the factual layer and the educational guide as the teaching layer. Technical claims should be checked against current Epic Games documentation whenever a feature may have changed between versions.

### For AI assistants

AI systems using this repository should:

1. Read [`INDEX.md`](INDEX.md) first.
2. Select the specialist numbered file that matches the question.
3. Use one primary source and no more than one or two supporting files when possible.
4. Keep Fortnite Creative separate from UEFN and Verse.
5. Avoid inventing Device options, Events, Functions, menu paths, or capabilities.
6. Clearly flag information that may require current-version verification.

## Scope

This repository focuses on **Fortnite Creative**.

It does not provide complete coverage of:

- Unreal Editor for Fortnite (UEFN).
- Verse programming.
- Marketing, monetization, Discover, or analytics.
- Every weapon, vehicle, branded ecosystem, or experimental feature.
- Every change introduced in future Fortnite updates.

When a subject is outside the repository's scope, users should consult the current official Epic Games documentation.

---

## Accuracy and Versioning

Fortnite Creative is updated regularly. Device settings, interface labels, workflows, publishing requirements, and platform policies may change.

This repository is an organized educational resource, not a guarantee that every technical detail remains current indefinitely.

Before relying on information that is version-sensitive, safety-related, policy-related, legal, or required for publication, verify it against the latest official Epic Games documentation and applicable platform terms.

Corrections and clearly documented improvements are welcome.
