## מכירים את מחזור העבודה

- ב-Create Mode משנים את העולם: מציבים עצמים, עורכים Devices ומשנים Island Settings.

- ב-Play Mode בודקים את החוויה מנקודת המבט של שחקן. לא מניחים ששינוי שעושים בזמן המשחק נשמר.

- Start Game מתחיל בדיקה. End Game מסיים אותה ומחזיר את האי למצב יצירה.

- Back to Hub או יציאה מהאי אינם תחליף ל-End Game.

## עובדים שלב אחר שלב

1.  פתחו את האי הפרטי שהוקצה לכם. המתינו עד שהסביבה נטענת במלואה.

2.  בדקו את סימון המצב על המסך. ודאו שאתם ב-Create Mode לפני כל פעולת עריכה.

3.  פתחו את ה-Sidebar ואתרו את Start Game. אל תשנו עדיין הגדרות אחרות.

4.  הפעילו Start Game. המתינו למסך תחילת המשחק ולנקודת ההופעה.

5.  נועו כמה צעדים ובדקו שהטלפון וכלי העריכה אינם זמינים כמו במצב יצירה.

6.  פתחו את Game Menu ובחרו End Game.

7.  ודאו שחזרתם ל-Create Mode ושאפשר שוב לבחור עצמים וכלים.

8.  חזרו על המחזור פעם נוספת בלי עזרה: Create → Start Game → Play → End Game → Create.

## בודקים במצב משחק

- במצב משחק נסו לבחור עצם. אם אי אפשר לערוך, אתם אכן ב-Play Mode.

- סיימו באמצעות End Game ובדקו שהעצמים וה-Devices חזרו למצב העריכה.

- בדקו שאינכם נמצאים ב-Hub או בתפריט הראשי במקום באי.

## תקלות נפוצות ופתרונן

| **מה רואים**                                    | **מה בודקים ועושים**                                                                                                                                                                                                             |
|-----------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **אי אפשר להזיז עצמים**                         | בדקו אם המשחק התחיל. סיימו את הבדיקה באמצעות End Game וחזרו ל-Create Mode.                                                           |
| **יצאתם מהאי**                                  | חזרו לאי הפרטי. בפעם הבאה השתמשו ב-End Game ולא ב-Leave.                                                                             |
| **לא מוצאים Start Game** | פתחו את ה-Sidebar. אם הכפתור אינו מופיע, ודאו שאתם בעלי הרשאת עריכה באי.                                                             |
| **השינוי נעלם אחרי הבדיקה**                     | שינויים שנעשו בזמן Play Mode אינם חלק מתהליך העריכה. חזרו ל-Create Mode ובצעו אותם שם. |

## בדיקת הבנה

- הסבירו במילים שלכם מה ההבדל בין Create Mode ל-Play Mode.

- בצעו מעבר מלא בין המצבים בלי להיעזר בהסבר חיצוני.

## תרגול באי הפרטי

- התחילו משחק, עברו במסלול קצר, סיימו אותו וחזרו בדיוק לאותה נקודת בנייה.

9.  בחרו עצם גדול וברור באי שישמש נקודת מוצא. אפשר להציב לידו סימן זמני.

## נושאים הדורשים אימות גרסה לפני הפקה

- קיצורי הדרך בפרק 1: התיעוד הרשמי העדכני מציג בין היתר ~ לבחירת Phone Tool, Tab לפתיחת Content Browser, M ל-Creative Menu ו-T ל-Heatmap. יש להשוות לגרסת המשחק ולמסמך המצורף לפני הדפסה.

- שמות Functions ו-Events המדויקים בכל Device: יש לבצע את כל התרגילים במשחק ולצלם את המסך שבו נבחרו.

- שיטת Register Item: במסכים מסוימים מבוצעת באמצעות Drop על ה-Device; בגרסאות או מכשירים מסוימים עשויה להופיע בחירה ישירה.

- סטטוס מצלמות, HUD Controller ויכולות מכינימה: פרק 17 הוא רשות ויש לבדוק Beta ומגבלות לפני הפקה.

- Backups ו-Restore: יש לאמת את מיקום האפשרויות ב-Island Overview של גרסת ההפקה.

- מסכי Creator Portal ותהליך הפרסום: עשויים להשתנות. הספר מציג היכרות בלבד והפעולה מתבצעת באמצעות חשבון בעל הרשאות מתאימות.
